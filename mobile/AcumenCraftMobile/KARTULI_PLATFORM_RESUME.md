# ქართული ხელოვნების პლატფორმა - ACUMEN CRAFT

## 🎨 მთავარი ხასიათი

**ACUMEN CRAFT** - ეს არის სრულად ქართულ ენაზე აგებული ძლიერი ხელოვნების პლატფორმა, რომელიც შექმნილია ქართველი მხატვრებისა და ხელოვნების მოყვარულებისთვის.

## ✨ მთავარი თვისებები

### 🏛️ ქართული დიზაინ სისტემა
- **BPG ExtraSquare** ქართული ფონტი
- **ოქროსფერი პალიტრა** (#8B5A2B - #FDF6C4)
- **ტრადიციული ქართული ფერები**
- **სრული ქართული ტერმინოლოგია**

### 📱 ქართული კომპონენტები
- **KartTeqsti** - ქართული ტექსტის კომპონენტი
- **KartGhilaki** - ქართული ღილაკი
- **KartKarti** - ქართული ბარათი
- **KartSheyvana** - ქართული შეყვანის ველი
- **KartThemeContext** - ქართული თემის მართვა

### 🎯 მთავარი ფუნქციები

#### 🏠 მთავარი გვერდი (HomeScreen)
- **ქართული მისალმება** - პერსონალიზებული მისალმება
- **სტატისტიკის ბარათები** - ნამუშევრები, შეფასება, მოწონება
- **ბოლო აქტივობები** - ყველა შეტყობინება ქართულ ენაზე
- **რეკომენდებული ნამუშევრები** - ქართული ხელოვნების შუქება

#### 🔍 აღმოჩენა (ExploreScreen)
- **ქართული ძიების სისტემა** - ნამუშევრების ძიება
- **კატეგორიების ფილტრი** - სურათები, ვიდეოები, AI შექმნილი
- **ბადისებური ლეიაუტი** - ლამაზი ნამუშევრების ჩვენება
- **ურიგო ჩატვირთვა** - Pull to refresh

#### 📤 ატვირთვა (UploadScreen)
- **მულტიმედია შერჩევა** - კამერა, გალერეა, ფაილები
- **ენობრივი ვერსიები** - ქართული, ინგლისური, გერმანული
- **კატეგორიზაცია** - ნახატი, ფოტოგრაფია, სკულპტურა და სხვა
- **ხელმისაწვდომობა** - საზოგადოებრივი/პირადი
- **AI მარკირება** - AI-ით შექმნილი ნამუშევრების მითითება

#### 👤 პროფილი (ProfileScreen)
- **სრული ქართული ინტერფეისი** - ყველა ელემენტი ქართულ ენაზე
- **სტატისტიკა** - ნამუშევრები, გამომწერები, მიყვება, შეფასება
- **პარამეტრები** - შეტყობინებები, ანგარიშის მართვა
- **მენიუ** - პროფილის რედაქტირება, ნამუშევრები, ნაკურნალებული

### 🔐 ავტორიზაცია (LoginScreen)
- **ქართული ფორმები** - ელ-ფოსტა და პაროლი
- **ვალიდაცია** - ქართული შეცდომის შეტყობინებები
- **UI კომპონენტები** - სრულად ქართული დიზაინი

## 🛠️ ტექნიკური დეტალები

### 📦 ფუნდამენტური ღირებულებები
```typescript
// ქართული თემის კონფიგურაცია
const KartTheme = {
  colors: {
    gold: { 50: '#FDF6C4', 600: '#8B5A2B', 700: '#7A4F24' },
    background: '#0A0A0A',
    surface: '#1A1A1A',
    text: '#FFFFFF'
  },
  typography: {
    fontFamily: 'BPG ExtraSquare'
  },
  spacing: { xs: 4, sm: 8, md: 16, lg: 24, xl: 32 }
}
```

### 🎨 კომპონენტების სტრუქტურა
```typescript
// ქართული კომპონენტის მაგალითი
<KartTeqsti

  varianti="satauri2"
  feri={theme.colors.gold[600]}
  teqstisGaswporeba="centri"
/>
```
