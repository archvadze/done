## 🚀 **როგორ ვაგრძელოთ**

### **დღეს გასაკეთებელი**
```bash
cd /var/www/done/mobile/AcumenCraftMobile
npx expo start
```

### **Development Workflow**
1. Expo Go app ჩამოტვირთეთ mobile device-ზე
2. QR code scan გაკეთეთ development server-დან
3. Hot reload მუშაობს ყველა ცვლილებისთვის

### **API Connection**
- Backend URL: `http://done.ddev.site:33000/api/v1`
- ყველა endpoint მზადაა integration-სთვის
- Authentication token-ები local storage-ში ინახება
