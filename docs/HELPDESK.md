## ❓ ხშირად დასმული კითხვები (FAQ)

**1. როგორ დავარეგისტრირო ანგარიში?**  
ვებგვერდზე დააჭირეთ "რეგისტრაცია" და შეავსეთ ფორმა.

**2. როგორ დავიცვა ჩემი საავტორო უფლებები?**  
ყველა ატვირთულ ნამუშევარზე უფლებები შენარჩუნებულია ავტორზე. დეტალებისთვის იხილეთ [USER_COPYRIGHT.md](./USER_COPYRIGHT.md).

**3. როგორ დავუკავშირდე ტექნიკურ მხარდაჭერას?**  
დაგვიკავშირდით ელ.ფოსტით ან GitHub Issue-ს გახსნით (იხილეთ ზემოთ).

**4. როგორ შემიძლია დავამატო/წავშალო ნამუშევარი?**  
პროფილიდან შეგიძლიათ ატვირთოთ ან წაშალოთ ნამუშევრები მარტივად.

**5. რა ხდება თუ ვიპოვე ბაგი ან უსაფრთხოების პრობლემა?**  
დაუყოვნებლივ მოგვწერეთ ელ.ფოსტაზე ან GitHub Issue-ში მიუთითეთ "bug/security".
