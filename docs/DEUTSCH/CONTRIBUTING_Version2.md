# Beitragende Richtlinien für Acumen Craft

_Letztes Update: 22.07.2025_

---

## Willkommen bei Acumen Craft!

Vielen Dank für dein Interesse, zu Acumen Craft beizutragen!  
Wir freuen uns über Pull Requests, Bug Reports, Vorschläge und jede andere Form der Mitwirkung.

---

## Wie kann ich beitragen?

### 1. Fehler melden / Feature vorschlagen

- Öffne ein [GitHub Issue](https://github.com/acumencraft/done/issues).
- Beschreibe das Problem oder den Vorschlag so detailliert wie möglich.
- Füge Screenshots, Fehlermeldungen oder Beispiel-Code bei, falls möglich.

### 2. Code beitragen

- Forke das Repository und erstelle einen neuen Branch (`feature/…` oder `bugfix/…`).
- Schreibe sauberen, dokumentierten und getesteten Code.
- Halte dich an unseren [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md).
- Füge, falls nötig, neue oder aktualisierte Tests hinzu.
- Stelle sicher, dass alle Tests erfolgreich sind (`npm test`, `php artisan test` etc.).
- Erstelle einen Pull Request mit einer klaren Beschreibung der Änderungen.

### 3. Dokumentation verbessern

- Korrigiere Tippfehler, füge Beispiele hinzu oder aktualisiere Inhalte.
- Dokumentations-Änderungen erfolgen idealerweise in eigenen Pull Requests.

---

## Stilrichtlinien

- **Code Style:** Befolge die bestehenden Formatierungsregeln (PSR-12 für PHP, Prettier für JS/TS/React, EditorConfig).
- **Commit Messages:** Aussagekräftige, kurze und englische Commit-Nachrichten (z.B. `fix: resolve image upload bug`).
- **Tests:** Schreibe Unit- und Integrationstests für neue Features/Bugfixes.
- **Branches:** Nutze sprechende Branch-Namen, z.B. `feature/nft-support`, `bugfix/login-redirect`.

---

## Review & Merge

- Alle Beiträge werden von Maintainer:innen überprüft.
- Sei offen für Feedback und passe deinen Pull Request ggf. an.
- Nach dem Merge kann dein Branch gelöscht werden.

---

## Rechtliches

- Durch das Einreichen eines Beitrags bestätigst du, dass du das Recht dazu hast und deine Arbeit kompatibel mit der [MIT-Lizenz](./LICENSE.md) ist.
- Keine urheberrechtlich geschützten Inhalte ohne nötige Lizenz/Berechtigung einreichen.
