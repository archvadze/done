# ადმინისტრატორის მართვის პანელი (Admin Panel)

ამ დოკუმენტში აღწერილია ადმინისტრატორის მართვის პანელის სრული ფუნქციონალი, რომელიც უზრუნველყოფს პლატფორმის ყოვლისმომცველ მართვას – დაწყებული საიტის პარამეტრების კონფიგურაციით და მომხმარებელთა მართვით, დასრულებული მოდერაციითა და AI მოდელების ადმინისტრირებით.

---

## 1. საერთო მიმოხილვა

ადმინისტრატორის პანელი ხელმისაწვდომია მხოლოდ ავტორიზებული ადმინისტრატორებისთვის და წარმოადგენს ცენტრალურ მართვის კონსოლს, საიდანაც შესაძლებელია პლატფორმის ყველა ასპექტის კონტროლი, მონიტორინგი და კონფიგურაცია.

---

## 2. ძირითადი შესაძლებლობები

### 2.1. საიტის ზოგადი პარამეტრების მართვა
- საიტის სახელის, ლოგოს, ფერების, favicon-ის და ბრენდინგის ცვლილება
- მთავარი გვერდის კონტენტის და ბანერების განახლება
- ენების დამატება/წაშლა/აქტივაცია (მულტილინგვა)
- კონტაქტური და იურიდიული ინფორმაციის რედაქტირება (Terms, Privacy, Copyright)
- ტექნიკური პარამეტრების მართვა (API keys, SMTP, 3rd-party ინტეგრაციები)

### 2.2. მომხმარებლების მართვა
- მომხმარებელთა სრული სია, ძიება, ფილტრაცია, სტატუსის ცვლილება (აქტიური/დაბლოკილი)
- მომხმარებლის პროფილის დეტალური ნახვა და რედაქტირება
- მომხმარებლის როლების მინიჭება/მოხსნა (user, მოდერატორი, ადმინი)
- მომხმარებლების წაშლა ან დროებითი შეჩერება
- მომხმარებლის აქტივობის ისტორიის ნახვა

### 2.3. მოდერატორთა მართვა
- მოდერატორების სიის ნახვა და რედაქტირება
- მოდერატორის როლის მინიჭება ან მოხსნა
- მოდერატორის უფლებების (პერმისიების) დალაგება

### 2.4. ნამუშევრებისა და კონტენტის მართვა
- ყველა ატვირთული ნამუშევრის სია, ძიება, ფილტრაცია
- ნამუშევრის სტატუსის ცვლილება (აქტიური, დამალული, წაშლილი)
- ხელოვნების ნიმუშის დეტალური ნახვა, აღწერის ან ტეგების რედაქტირება
- კონტენტის წაშლა ან არქივაცია
- კონტენტის ავტორების მართვა

### 2.5. კატეგორიების, ტეგების და თემების მართვა
- ახალი კატეგორიის/ტეგის/თემის შექმნა, რედაქტირება, წაშლა
- იერარქიის ცვლილება (drag & drop)
- კატეგორიზაციის სისტემის კონფიგურაცია

### 2.6. შეფასების (ACQ) სისტემის მართვა
- შეფასების ალგორითმის პარამეტრების ცვლილება
- შეფასების ისტორიისა და სტატისტიკის ნახვა
- ქულების გადათვლა ან ხელით კორექცია

### 2.7. მოდერაცია და უსაფრთხოება
- Flag/Report queue – მომხმარებელთა მიერ მონიშნული კონტენტის მართვა
- ავტომატური და ხელით მოდერაციის სისტემების მართვა
- მიმოწერების მონიტორინგი (GDPR-ს შესაბამისი ლოგირება)
- ანგარიშების დაბლოკვა/გაუქმება

### 2.8. ფინანსური ოპერაციები და ანალიტიკა
- გადახდების სტატისტიკის ნახვა (Stripe, PayPal, კრიპტო)
- დონაციების, ტრანზაქციების ისტორია
- ფინანსური რეპორტინგი და ექსპორტი

### 2.9. შეტყობინებებისა და კომუნიკაციის მართვა
- სისტემური შეტყობინებების გაგზავნა (email, push, in-app)
- მომხმარებლების სეგმენტაცია შეტყობინებებისთვის
- წინასწარ განსაზღვრული შეტყობინებების შაბლონების რედაქტირება

### 2.10. სისტემური ლოგები და მონიტორინგი
- სისტემური მოვლენების ლოგების ნახვა (login, შეცდომები, ცვლილებები)
- უსაფრთხოების ინციდენტების მონიტორინგი
- სისტემის ჯანმრთელობის სტატუსი (uptime, CPU, storage)

### 2.11. AI მოდელების მართვა
- ხელოვნური ინტელექტის სხვადასხვა მოდულის (ACQ, Recommendation, Content Moderation და სხვა) მართვა
- ახალი მოდელის ატვირთვა ან არსებული მოდელის განახლება
- მოდელის პარამეტრების ცვლილება, აქტივაცია/დეზაქტივაცია
- მოდელის შესრულების სტატისტიკა და ლოგები

### 2.12. API და Developer Access
- API key-ების გენერაცია და მართვა
- Rate limit-ის და სხვა API პარამეტრების კონტროლი
- დეველოპერებისთვის sandbox-გარემოს ადმინისტრირება

### 2.13. პლატფორმის ვერსიების და განახლებების მართვა
- მიმდინარე პლატფორმის ვერსიის ნახვა
- განახლებების ლოგი და Rollback-ის შესაძლებლობა
- სისტემის სარეზერვო ასლების მართვა

---

## 3. უსაფრთხოება

- ყველა ადმინისტრატორული ქმედება ლოგირდება და დაცულია მრავალფაქტორიანი ავთენტიკაციით (2FA)
- დეტალური უფლებების დაყოფა (RBAC – Role Based Access Control)
- GDPR/CCPA შესაბამისი მომხმარებლების მონაცემთა მართვა

---

## 4. გამოყენების მაგალითები

- **საიტის ვიზუალური თემის შეცვლა:** ადმინი ცვლის ფერს, ლოგოს ან მთავარ გვერდს.
- **მომხმარებლის დაბლოკვა:** პრობლემური მომხმარებლის აღმოჩენისას ადმინი დროებით აჩერებს მის ანგარიშს.
- **ახალი AI მოდელის დანერგვა:** ახალი შეფასების ან რეკომენდაციის მოდელის ატვირთვა და ტესტირება.
- **ფინანსური ანგარიშგება:** გადახდებისა და შემოსავლის სრულყოფილი სტატისტიკის მიღება.
- **მრავალენოვნების მართვა:** ახალი ენის დამატება ან არსებული თარგმანის განახლება.
- **მოდერატორის უფლებების კორექტირება:** ახალ მოდერატორს ეძლევა მხოლოდ კონკრეტული კატეგორიების მართვის უფლება.

---

## 5. რეკომენდაციები და საუკეთესო პრაქტიკა

- გამოიყენეთ ძლიერი პაროლები და 2FA ყველა ადმინისტრატორისთვის
- რეგულარულად განაახლეთ პლატფორმა და AI მოდელები
- პერიოდულად შეამოწმეთ სისტემური ლოგები და უსაფრთხოების სტატუსი
- მინიმალური უფლების პრინციპი: მხოლოდ საჭირო წვდომა თითოეულ როლს
